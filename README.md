# Clean The Supermarket

لعبة FPS ثلاثية الأبعاد بـ Godot 4.5 — امشِ في السوبرماركت، اجمع المنتجات من الأرض، وحطهم على الرف الصح.

## التشغيل

1. حمّل [Godot 4.5+](https://godotengine.org/download)
2. افتح المجلد في Godot
3. اضغط F5

أو من سطر الأوامر:

```bash
godot --path .
```

## التحكم (ديسكتوب)

| المفتاح | الوظيفة |
|---|---|
| WASD | حركة |
| الماوس | نظر |
| E / كليك | رفع من الأرض / وضع على الرف |
| Q | ترمي أعلى منتج |
| 1 - 4 | القدرات الخاصة |
| U | متجر الترقيات |
| P | إيقاف مؤقت |
| Tab | تبديل قفل المؤشر |

## الموبايل

عصا حركة يسار + اسحب للنظر + أزرار يمين (تفاعل، ترمي، متجر، إيقاف).

## Gameplay

- **852 منتج** متناثرة على الأرض
- **6 أقسام** ملونة: Fruits, Dairy, Drinks, Snacks, Cleaning, Frozen
- كل منتج لازم يروح على رف قسمه
- كل ضبط صح = **$1**
- اصرف الكاش على: سرعة، مسافة تفاعل، سعة حمولة، و4 قدرات

## القدرات (تُفتح من المتجر)

1. **Reveal Matching** — يضوي كل منتجات نفس النوع على الأرض
2. **Grab Pairs** — تاخد منتجين مرة واحدة
3. **Find Shelves** — يضوي الرفوف اللي محتاجاها
4. **Organize Load** — يرتب الحزمة حسب النوع

## البنية

```
project.godot
scenes/main.tscn
scripts/
  autoload/game_state.gd   # الحالة العامة: cash, upgrades, powerups
  main.gd                  # بناء السوبرماركت + توزيع المنتجات
  player.gd                # المتحكم FPS + الحزمة + التفاعل
  product.gd               # منتج على الأرض
  shelf.gd                 # رف القسم
  ui.gd                    # HUD + المتجر + الإيقاف + الموبايل
```
